CPU scheduling

Ambulance preemptive priority, normal vehicles FCFS per direction, signals Round Robin.

1
🚑 Ambulance

Preemptive priority. Detected on arrival, interrupts a crossing vehicle, FCFS among ambulances. One all-red unit keeps conflicting directions from being green together.

2
🚗 Normal vehicles

FCFS inside each directional queue. A later vehicle never overtakes an earlier one in the same direction.

3
🚦 Traffic signals

Round Robin N → S → E → W with the time quantum. Empty or disabled directions are skipped.

Memory & resource management

Each road approach is a limited resource: vehicles request, get allocated and release lane slots.

DirectionCapacityCurrent allocationAvailableQueue demandStatus
How to read this: Capacity = lane slots per direction. Current allocation = slots held right now (a vehicle requests a slot when it arrives, is allocated one if free, and releases it after crossing). Available = capacity − allocation. Queue demand = vehicles currently wanting that lane. If demand is higher than allocation, a capacity exceeded warning is shown and the extra vehicles wait for a free slot. Lane capacity and intersection capacity are simplified OS-resource analogies, not literal computer memory.

Real-time scenario handler

Test different traffic conditions in a safe virtual environment.

Selected: Normal traffic

Congestion adds extra cars during the window. Accident blocks the affected approach and diverts vehicles until it clears. Signal failure disables the affected signal (it never shows green) while the other signals keep rotating; an ambulance there is served under manual override. Ambulance injects an ambulance at the start time on the affected approach. Normal operation is restored when the scenario ends. Simplified for an educational single-intersection simulator.
